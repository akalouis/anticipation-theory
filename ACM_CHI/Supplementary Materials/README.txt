This supplementary material contains the following files and folders:
.
├── Code/
├── Demo/
└── README.txt

1. Code/
   - Project created using Visual Studio 2022.
   - Uses Windows SDK version 10.0 (default project setting) and C++20.
   - Should build and run on most Windows environments with Visual Studio installed.
   - Open the project via 'Code/AnticipationTheory.sln'.
   - In 'main.cpp', specify the desired program_code in the main() function before building and running (e.g., hpgame).

2. Demo/
   - Browser-playable demo that can be run directly in a modern browser (e.g., Chrome).
   - Includes 'Demo/hpgame.html' and 'Demo/hpgame_rage_optimized.html'.
   - No installation is required; just open the HTML files in a browser to play with the demo.
